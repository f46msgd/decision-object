# Contributing

Thanks for helping. This is a small draft spec, so the bar is simple:

- **Open an issue first** for any change to the schema. Include at least one real (anonymized) decision an agent asked you that the current format expresses badly, and what you'd change.
- **New examples are always welcome** as pull requests: put them in the fitting folder under `examples/`, add a row to `examples/INDEX.md`, and make sure `validate.py` passes.
- Keep examples free of personal data, real customer names, credentials, and internal URLs.
- If you used AI assistance, say so in the issue or PR and how much. That's fine; we just want to know.

By contributing you agree your contribution is licensed under Apache-2.0.
